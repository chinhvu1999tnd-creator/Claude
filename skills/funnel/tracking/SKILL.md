# Tracking Skill — Funnel Pixel Injection

> Load skill này SAU KHI funnel đã build và deploy xong.
> Trước khi chạy: xác nhận user đang đứng trong thư mục funnel cần track (vd: `output/funnel/sales/ten-san-pham/`).

---

## Load Order

```
1. tracking-config.json (nếu đã có từ lần trước)
2. funnel.json (đọc product_name, price, funnel_type)
3. references/event-mapping.md
4. references/utm-capture.md
5. Nếu user có Access Token:
   → references/meta-capi.md
   → references/tiktok-events.md
   → references/ga4-measurement.md
```

## Bước 1 — Configure

### 1a. Đọc funnel context

Đọc `funnel.json` trong thư mục hiện tại. Extract:
- `product_name` → dùng làm `content_name` cho ViewContent event
- `price` → dùng làm `value` cho Purchase/InitiateCheckout
- `funnel_type` → xác định events nào sẽ fire (lead funnel: Lead event; sales funnel: Purchase event)

Nếu không có `funnel.json` → hỏi user:
```
Em cần biết thêm:
1. Tên sản phẩm/dịch vụ?
2. Giá bán (VND)?
3. Loại phễu? (lead / sales / webinar / booking)
```

### 1b. Hỏi Pixel IDs

```
Để inject tracking, anh/chị cần cung cấp Pixel IDs cho các platform đang dùng.
Bỏ qua platform nào không chạy ads.

Platform nào anh/chị muốn cài tracking?

[ ] Meta / Facebook Ads
    → Pixel ID: _____________ (VD: 1234567890123456)
    → Access Token: _________ (optional — bật server-side tracking, match rate cao hơn)
    → Test Event Code: ______ (optional — để test trong Events Manager)

[ ] TikTok Ads
    → Pixel ID: _____________ (VD: CXXXXXXXXXXXXXXXX)
    → Access Token: _________ (optional)

[ ] Google Ads / GA4
    → Measurement ID: _______ (VD: G-XXXXXXXXXX)
    → API Secret: ___________ (optional — bật server-side)
```

**Quy tắc:**
- Pixel ID là BẮT BUỘC cho mỗi platform chọn — không có thì bỏ qua platform đó
- Access Token là OPTIONAL — nếu không có thì chỉ browser tier hoạt động
- Không hỏi thêm thông tin nào khác — giữ bước configure ngắn gọn

### 1c. Ghi tracking-config.json

Ghi vào thư mục funnel (cùng cấp với index.html):

```json
{
  "_comment": "Auto-generated by tracking skill. DO NOT edit manually — re-run /tracking configure.",
  "product_name": "[từ funnel.json hoặc user input]",
  "price": 997000,
  "currency": "VND",
  "funnel_type": "sales",
  "platforms": {
    "meta": {
      "pixel_id": "[META_PIXEL_ID hoặc null]",
      "test_event_code": "[TEST_EVENT_CODE hoặc null]"
    },
    "tiktok": {
      "pixel_id": "[TIKTOK_PIXEL_ID hoặc null]"
    },
    "google": {
      "measurement_id": "[G-XXXXXXXXXX hoặc null]"
    }
  },
  "server_side_enabled": false,
  "events": {
    "page_view": true,
    "view_content": true,
    "lead": true,
    "initiate_checkout": true,
    "purchase": true,
    "scroll_depth": [25, 50, 75, 90],
    "time_on_page_seconds": 60
  }
}
```

**Access Tokens KHÔNG ghi vào tracking-config.json** — ghi vào `.env`:
```
META_ACCESS_TOKEN=...
TIKTOK_ACCESS_TOKEN=...
GA4_API_SECRET=...
```

Thêm vào `.gitignore` nếu chưa có: `.env`

Update `.env.example`:
```
# Tracking — Pixel IDs (public, có thể commit)
META_PIXEL_ID=           # lấy từ Events Manager
TIKTOK_PIXEL_ID=         # lấy từ TikTok Ads Manager
GA4_MEASUREMENT_ID=      # lấy từ Google Analytics → Data Streams

# Tracking — Access Tokens (private, KHÔNG commit)
META_ACCESS_TOKEN=       # Graph API token — bật server-side tracking
TIKTOK_ACCESS_TOKEN=     # TikTok Business API token
GA4_API_SECRET=          # GA4 Measurement Protocol API secret
```

## Bước 2 — Inject

### 2a. Generate tracking.js

Copy template từ `skills/funnel/tracking/templates/tracking.js`.
Thay thế các placeholder:
- `{{FACEBOOK_PIXEL_ID}}` → giá trị từ tracking-config.json (hoặc `null`)
- `{{TIKTOK_PIXEL_ID}}` → giá trị hoặc `null`
- `{{GA4_MEASUREMENT_ID}}` → giá trị hoặc `null`
- `{{PRODUCT_NAME}}` → product_name
- `{{PRODUCT_PRICE}}` → price
- `{{CURRENCY}}` → `VND`
- `{{SERVER_SIDE_ENABLED}}` → `true` hoặc `false`

Lưu file tại: `tracking.js` (cùng cấp với index.html)

### 2b. Inject script tag vào tất cả HTML files

Với mỗi file `.html` trong funnel folder (bao gồm subdirectories):
1. Tìm `</head>` tag
2. Chèn TRƯỚC `</head>`:

```html
  <!-- Tracking — Auto-injected by tracking skill -->
  <script src="/tracking.js" defer></script>
```

**Lưu ý:** Dùng đường dẫn tuyệt đối `/tracking.js` (không phải `./tracking.js`) vì các subpage (thank-you/, order/) cần resolve đúng từ root.

### 2c. Wire Lead event vào form handlers

Tìm trong các HTML files: form có `onsubmit` handler hoặc submit button.

Pattern nhận biết form opt-in / lead:
```js
// Tìm: function handle[Xxx](event) { hoặc form.addEventListener('submit',
// Thêm Analytics.track ngay TRƯỚC khi form được process:
```

Chèn vào đầu submit handler:
```js
// Tracking — Lead event
if (window.Analytics) {
  const emailEl = this.querySelector('input[type="email"]') || document.querySelector('input[type="email"]');
  const phoneEl = this.querySelector('input[type="tel"]') || document.querySelector('input[type="tel"]');
  Analytics.track('Lead', {
    email: emailEl ? emailEl.value : null,
    phone: phoneEl ? phoneEl.value : null
  });
}
```

### 2d. Wire InitiateCheckout vào payment buttons

Tìm các button/link có text hoặc class liên quan đến payment:
- Text: "Mua ngay", "Thanh toán", "Đăng ký", "Chuyển khoản", "Xem QR"
- Class: `btn-buy`, `btn-payment`, `btn-qr`, `payment-btn`
- onclick handler hiện tại có `showQR`, `openPayment`, `showPayment`

Thêm vào onclick handler:
```js
// Tracking — InitiateCheckout event
if (window.Analytics) {
  Analytics.track('InitiateCheckout', {
    value: CONFIG.price,
    currency: 'VND'
  });
}
```

### 2e. Verify inject thành công

Kiểm tra index.html:
```bash
grep -c "tracking.js" index.html
# Expected: 1

grep -c "Analytics.track" index.html
# Expected: ≥ 1 (nếu page có form hoặc payment button)
```

## Bước 3 — Server-side (chỉ khi user có Access Token)

Nếu user không cung cấp Access Token nào → bỏ qua bước này hoàn toàn.

### 3a. Generate api/tracking.js

Copy template từ `skills/funnel/tracking/templates/api-tracking.js`.
Không cần thay placeholder — file đọc từ `process.env` lúc runtime.

Lưu tại: `api/tracking.js`

### 3b. Patch api/webhook.js — thêm Purchase event

Tìm file `api/webhook.js`. Sau block "Email delivery" hoặc sau block cuối cùng trong try{}, thêm:

```js
// Tracking — Purchase event (server-side)
try {
  const { fireServerPurchase } = await import('./tracking.js');
  await fireServerPurchase({
    event_id: `purchase_${transaction.reference || Date.now()}`,
    order_id: transaction.reference,
    value: transaction.amount,
    currency: 'VND',
    email: transaction.customerEmail || null,
    phone: transaction.customerPhone || null,
    ip: req.headers['x-forwarded-for'] || req.socket?.remoteAddress,
    user_agent: req.headers['user-agent']
  });
} catch (trackErr) {
  console.error('[Tracking] Purchase event failed:', trackErr.message);
  // Non-blocking — không throw, không ảnh hưởng webhook response
}
```

### 3c. Update vercel.json

Thêm route cho `/api/tracking`:

```json
{
  "rewrites": [
    { "source": "/api/tracking", "destination": "/api/tracking.js" }
  ]
}
```

Nếu `vercel.json` đã có `rewrites` array → append vào array đó, không replace.

### 3d. Verify server-side setup

```bash
ls api/tracking.js
# Expected: file exists

grep "fireServerPurchase" api/webhook.js
# Expected: 1 match
```

## Test Events

Hướng dẫn test sau inject:

**Meta:** Vào Events Manager → Test Events → nhập Test Event Code (nếu đã cấu hình) → mở trang funnel → check events appearing.

**TikTok:** Dùng TikTok Pixel Helper Chrome extension → mở trang funnel → kiểm tra events.

**GA4:** Vào GA4 → DebugView → bật GA4 DebugMode bằng Chrome extension "Google Analytics Debugger" → mở trang funnel.
