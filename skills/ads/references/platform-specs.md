# Platform Specs — Character Limits & Format Requirements

---

## Meta Ads (Facebook & Instagram) — Priority 1

### Single Image / Video / Carousel

| Element | Recommended | Maximum | Notes |
|---------|-------------|---------|-------|
| Primary text | 125 chars | 2,200 chars | Truncated sau 125 — hook phải ở đây |
| Headline | 40 chars | 255 chars | Below image |
| Description | 30 chars | 255 chars | Below headline, có thể không show |

**Placement notes:**
- **Feed**: Tất cả elements show, primary text visible nhất
- **Stories/Reels**: Primary text overlay — giữ dưới 72 chars
- **Right column**: Chỉ headline visible — bỏ description

**Best practices:**
- Front-load hook vào 125 chars đầu
- Line breaks cho readability trong primary text dài
- Emojis: test, max 1-2/ad
- Questions trong primary text tăng engagement
- Headline = clear CTA hoặc value statement

### Ad Image Specs

| Placement | Ratio | Size |
|-----------|-------|------|
| Feed | 1:1 | 1080×1080 |
| Stories/Reels | 9:16 | 1080×1920 |
| Landscape | 1.91:1 | 1200×628 |
| Carousel card | 1:1 | 1080×1080 |

## TikTok Ads — Priority 2

### In-Feed Ads

| Element | Recommended | Maximum |
|---------|-------------|---------|
| Ad text | 80 chars | 100 chars |
| Display name | — | 40 chars |
| CTA | Platform options | Predefined |

**Video specs:** Vertical 9:16 · 1080×1920 · Recommended 15-60 giây

**TikTok-specific:**
- Native-feeling content outperforms polished ads
- 2 giây đầu quyết định watch rate
- Trending sounds + formats tăng distribution
- Text overlay bắt buộc — phần lớn xem không có âm thanh
- Vertical video only

## Google Ads

### Responsive Search Ads (RSAs)

| Element | Limit | Required | Notes |
|---------|-------|----------|-------|
| Headline | 30 chars | 3 min, 15 max | Google ghép ngẫu nhiên — mỗi headline phải stand-alone |
| Description | 90 chars | 2 min, 4 max | 2 descriptions show cùng lúc |
| Display path 1 | 15 chars | Optional | Sau domain trong URL |
| Display path 2 | 15 chars | Optional | Sau path 1 |

**Headline mix (15 headlines):**
- 3-4 keyword-focused (match search intent)
- 3-4 benefit-focused
- 2-3 social proof (số liệu, giải thưởng)
- 2-3 CTA-focused
- 1-2 differentiators
- 1 brand name

**Description mix (4 descriptions):**
- 1 benefit + proof point
- 1 feature + outcome
- 1 social proof + CTA
- 1 urgency/offer + CTA (nếu có)

### Performance Max

| Element | Limit |
|---------|-------|
| Headline | 30 chars (5 required) |
| Long headline | 90 chars (5 required) |
| Description | 90 chars (1 required, 5 max) |

## Character Counting Rules

- **Spaces** tính là ký tự trên tất cả platforms
- **Emoji** tính là 1-2 ký tự
- **Special chars** (|, &, ...) tính là 1
- **URLs** trong body text tính vào limits
- Luôn verify trong platform preview trước khi launch

---

## Multi-Platform Adaptation

Khi cần tạo cho nhiều platform cùng lúc, bắt đầu từ restrictive nhất:

```
1. Google Search headline (30 chars) — tightest messaging
2. Expand → Meta headline (40 chars)
3. Expand → LinkedIn intro (150 chars)
4. Expand → Meta primary text (125+ chars)
```

Core message phải work ở mọi nơi, sau đó enrich cho platform có nhiều space hơn.
